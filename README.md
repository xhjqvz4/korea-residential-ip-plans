## 原生 IP、住宅 IP、双 ISP、静态 IP，四个词不是一回事

搜「韩国原生家宽IP」的人经常被这四个词绕进去，而不少推荐文把「原生」直接当「住宅」卖。

判定链条其实很短：服务器物理机在韩国，IP 由韩国本土宽带运营商分配，ASN 查询结果指向韩国 ISP 而不是云服务商。三条同时满足，才算原生 IP。原生 IP 之上还有一层，IP 段本身属于家庭宽带，在风控模型里读出来是「一个住在韩国的普通家庭用户」，这才是住宅 IP。原生不等同于住宅，原生也可能落在机房段里。

「双 ISP」是说这个 IP 在数据库里同时挂着两个 ISP 属性，被判定为代理的概率会更低一层。「静态」只说一件事：每次开机 IP 不变。静态和住宅没有任何关系，机房 IP 也可以是静态的。

把这四个词分清之后，你就能看懂 WePC 这款的定位：SEJONG 机房 + 韩国本土运营商分配 + 双 ISP 家宽属性，属于「原生 + 住宅」两层都占。而第一款「韩国原生IP_TK专用」只承诺了原生，没承诺住宅。

## 开通后先验这三件事

第一件，ASN 归属。用 ipinfo.io 或 ip.sb 查一下，确认 ASN 指向韩国本土 ISP，不是云服务商。这一步决定你拿到的是不是原生 IP。

第二件，风险分。scamalytics.com 查一下，住宅 IP 通常落在 10–25 之间。分数明显偏高，说明这个 IP 段被前人用得很重，风控表现会打折。

第三件，也是最容易翻车的一件：TikTok 和流媒体的实际 region。

第三方测评对这台机器的结论是：Netflix、Disney+ 韩国区解锁正常，韩国 AI 平台访问正常，YouTube 4K 播放流畅，国内平均延迟约 76ms，电信和移动直连表现较好。但同一条测评里明确写了「TikTok 实测识别为新加坡，直播建议搭配中转」。

官网给这款套餐的定位是「TIKTOK视频/直播自然推流」。第三方实测的 region 判定却是新加坡。这两条信息放在一起看，结论只有一个：别把「韩国双 ISP 家宽 IP」直接等同于「韩区 TikTok 可用」。拿到机器第一件事是打开 TikTok 看它判你哪个区，再决定要不要投入运营。做直播的话，测评方给的建议是搭配中转。

延迟方面，76ms 是第三方单点测试的平均值，你自己那边的实际表现取决于当地运营商和时段。联通用户要特别注意，官网和第三方都写了联通绕路，这一条是明示的，不是偶发。
